About this dashboard

Transparent assumptions. Bounded conclusions.

For a family-office client planning USD reserves. The date check compares a spending date with reference maturities; it does not certify settlement, cash availability or suitability. Results use a saved quote-date model, not today's executable prices.

Observed data

    The bank discount quote uses face value and a 360-day year. It is not a holding-period return or the class ontology's yield-to-maturity measure. CPI observation months, release dates and retrieval dates serve different purposes.

    User assumptions and model limits

    Principal and effective annual inflation are hypothetical. The model assumes purchase on the saved quote date, fractional holdings, no costs, and holding to maturity. Reference tranche labels need not equal remaining days. Actual settlement, execution, tax and purchase denominations may change outcomes.

    Future CPI, reinvestment rates and early-sale prices are unknown. A fixed-dollar obligation need not beat inflation. No rollover strategy or post-maturity return is modeled.

    Financial formulas and rounding

    Price per $100 = 100 × (1 − discount rate × days / 360)

    Nominal proceeds = principal × 100 / price

    Inflation factor = (1 + annual assumption)^(days / 365)

    Purchasing power = nominal proceeds / inflation factor

    Break-even annual inflation = (nominal proceeds / principal)^(365 / days) − 1

    Principal + nominal interest − purchasing-power adjustment = purchasing power

    Rates in formulas are decimals. Days are exact UTC calendar-date differences from quote to maturity; inflation uses a fixed 365-day exponent, including leap years. Headline amounts round to dollars; the decomposition and text tables use cents. Changes below half a displayed unit are described as approximately unchanged, without negative zero. Calculations retain full precision.

    Freshness, missing values and maintenance

    Device date only controls age and matured-reference labels; it never changes the model start. Reference bills whose maturity has passed are labeled historical, not currently available. Source quote/CUSIP/maturity correspondence must be checked before a release.

    Historical charts use the last saved quote in each calendar month and CPI by observation month. One common window is anchored to the latest saved month; no series is shifted to look aligned. Missing observations remain gaps. Rates have a labeled, non-zero-based line-chart scale. CPI uses the downloaded vintage, not a publication-time backtest.

    The page uses saved local data. Manual maintenance prepares a separate candidate, checks dates, units and results, and stops for human acceptance. No external market-data requests, automatic trading or running AI agent.
